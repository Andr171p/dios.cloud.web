# План начала разработки

1. **Brand Foundation**. Утвердить типографику, цветовые токены, светлую и тёмную темы, геометрию компонентов, логотипы продуктов.
2. **Focused Product Carousel**. Реализовать окончательную механику карусели на Embla, включая центрированный активный слайд, соседние previews, клавиатуру и responsive-поведение.
3. **Product Demo System**.  Разработать компонент демонстрации интерфейса с poster, видео, управлением воспроизведением и оптимизацией загрузки.
4. **Payload Content Model**. Добавить Products, Homepage, Media и ограниченный набор контентных блоков. Подключить данные к уже готовым компонентам.
5. **Полная композиция главной страницы**. Реализовать Connected Ecosystem, Use Cases, блок доверия, навигацию и Footer, после чего провести визуальное и техническое тестирование.
