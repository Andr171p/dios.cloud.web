# Карусель продуктов

## Референс

В качестве референса взята карусель с [СберТех](https://sbertech.ru/?utm_referrer=https%3A%2F%2Fwww.google.com%2F)

![Карусель СберТех](docs/features/sbertech-carousel.png)

### Что обеспечивает хорошую визуальную иерархию?

 - Центральная карточка заметно крупнее.
 - Соседние элементы затемнены.
 - Активный элемент имеет более чёткую границу.
 - Вокруг активного элемента оставлено пространство.
 - Стрелки вынесены за пределы основного ряда.
 - Изменение визуального веса сразу объясняет, какой элемент выбран.

Для DIOS это можно перенести почти полностью, но заменить портреты на продуктовые демонстрации.

Но есть нюанс: визуально большая карточка не обязательно должна занимать больше места в layout.

Я бы использовал одинаковую геометрическую ширину слайдов внутри Embla, а масштаб менял только через CSS `transform: scale()`.

Так Embla продолжит корректно рассчитывать scroll snap points, и карусель будет работать стабильнее.

| Состояние | Scale | Opacity | Дополнительно |
|---|---|---|---|
| Активный | 1.00 | 1.00 | Чёткая граница, полное содержимое |
| Соседний | 0.88–0.92 | 0.55–0.70 | Приглушённый контент |
| Дальний | 0.82–0.86 | 0.30–0.45 | Только визуальный preview |
| Hover неактивного | +0.03–0.05 | +0.15 | Подсказка интерактивности |

Не рекомендую делать активную карточку ещё больше при наведении. Она уже является главным элементом. Лучше реагировать на hover через лёгкое изменение границы и небольшое увеличение внутреннего изображения.

### Как взаимодействовать с карточками

Здесь важно разделить `hover`, `selected` и `focused`.

 - `hover` — пользователь навёл указатель, мы лишь показываем возможность действия;
 - `selected` — продукт активен в карусели, отображаются его подробности;
 - `focused` — элемент выбран клавиатурой, показывается заметный focus indicator.

Переключение по клику на соседнюю карточку, а не по наведению. Иначе пользователь будет случайно менять активный продукт, просто перемещая мышь через карусель.

### Центрирование карусели и одинаковое количество прокруток

Для 5 продуктов индекс старта будет 2, для 7 — 3.

Однако при двух продуктах невозможно иметь одинаковое число уникальных переходов влево и вправо без циклического повторения.

Поэтому я предлагаю:
- Для 1 продукта вообще не показывать полноценную карусель.
- Для 2 продуктов использовать специальную двухпозиционную композицию или обычное переключение.
- Для 3+ продуктов использовать центрированную карусель.
- Для чётного количества продуктов выбирать один из двух центральных элементов; идеальная симметрия числа переходов невозможна без повторов.
  
В Embla v8 есть параметры `align: "center"` и `startIndex`; при этом `containScroll: "trimSnaps"` может переопределять центрирование крайних слайдов. Это необходимо учитывать при дизайне.

### Прокрутка тачпадом: как правильно реализовать

В Embla есть отдельный плагин `embla-carousel-wheel-gestures`, который добавляет поддержку wheel и trackpad gestures.
Он позволяет прокручивать слайды непосредственно жестами, а не только кнопками или перетаскиванием.

**Важное UX решение**

Не нужно превращать обычную вертикальную прокрутку страницы в горизонтальную прокрутку карусели.

Лучше:
 - Горизонтальный жест двумя пальцами — переключение продуктов.
 - Вертикальный жест — обычный скролл сайта.
 - Drag мышью — перемещение карусели.
 - Кнопки — переход по одному продукту.
 - Клавиатура — переключение при фокусе внутри карусели.

### Масштабирование и затемнение

Состояние выбранного элемента лучше получать от Embla через `selectedScrollSnap()`.

Простейшая схема:

```typescript
const [selectedIndex, setSelectedIndex] = useState(initialIndex);

useEffect(() => {
  if (!emblaApi) return;

  const onSelect = () => {
    setSelectedIndex(emblaApi.selectedScrollSnap());
  };

  onSelect();

  emblaApi.on("select", onSelect);
  emblaApi.on("reInit", onSelect);

  return () => {
    emblaApi.off("select", onSelect);
    emblaApi.off("reInit", onSelect);
  };
}, [emblaApi]);
```

Дальше на слайды можно передавать атрибут:

```typescript
<div
  className="product-slide"
  data-active={index === selectedIndex}
>
  <ProductCard product={product} />
</div>
```

И применять стили:

```css
.product-slide {
  transform: scale(0.9);
  opacity: 0.55;
  transition:
    transform 400ms cubic-bezier(0.22, 1, 0.36, 1),
    opacity 300ms ease;
}

.product-slide[data-active="true"] {
  transform: scale(1);
  opacity: 1;
}

@media (hover: hover) and (pointer: fine) {
  .product-slide:not([data-active="true"]):hover {
    transform: scale(0.94);
    opacity: 0.8;
  }
}

@media (prefers-reduced-motion: reduce) {
  .product-slide {
    transition: none;
  }
}
```
